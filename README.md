# Composio 100-App Research

Research and analysis of 100 applications across 10 categories, focusing on API accessibility, authentication, access models, MCP support, and buildability.

## Research Scope

- 100 apps
- 10 categories
- Authentication methods
- Self-serve vs gated access
- REST / GraphQL APIs
- MCP support
- Buildability considerations
- First-party documentation and evidence

## Categories

1. CRM
2. Customer Support
3. Communication
4. Marketing & Advertising
5. E-commerce
6. Web Data & Scraping
7. Developer & Infrastructure
8. Productivity & Project Management
9. Finance & Payments
10. AI & Knowledge Tools

## Project Files

- `apps.json` — 100-app research list
- `researcher.py` — research pipeline
- `structure_results.py` — structures research results
- `verifier.py` — verification workflow
- `case_study.html` — final interactive case study
- `analysis_summary.json` — aggregated research analysis
